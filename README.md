# Zotero 网盘按需同步

这是一个仅支持 **Zotero 10** 的实验性插件。它用夸克网盘或百度网盘同步个人库附件，一次只使用一个网盘。同步由用户手动发起，结束后关闭仅监听 `127.0.0.1` 的临时 WebDAV 接口。条目和笔记仍按 Zotero 原有设置同步。

当前版本 **0.2.2**：设置页不再提供「测试读写」按钮；夸克改填网盘目录路径，不需要文件夹 ID。旧版本的改动见 [版本记录](CHANGELOG.md)。

**使用前请备份文献库。** 尚未验证真实百度或夸克账号的端到端同步，不要直接用唯一的文献库试用。

## 安装和首次使用

1. 在 Zotero 的「工具 → 插件」中用齿轮菜单「从文件安装插件」选择构建生成的 `outputs/cloud-on-demand-0.2.2.xpi`。若安装失败，请保留错误信息，不要修改兼容性限制。
2. 从「工具 → 网盘按需同步 → 同步设置…」打开窗口。选择一个网盘并扫码授权，再填写已创建的专用目录。
3. 备份文献库并勾选实验版确认，保存配置后，先用测试文献库点击「开始同步」。保存配置本身不会连接网盘。请勿将 Cookie、SecretKey 或 Token 发到聊天、公开 issue 或第三方网站。

### 夸克

- 用夸克 App 扫码。扫码不可用时，可从官方网页请求头复制 Cookie 到设置页「高级」中。
- 填写网盘中的完整路径，例如 `/文献/Zotero`。路径以 `/` 开头，不填根目录，末尾不加 `/`。附件仍存入该目录下的 `zotero` 子目录。旧版保存过文件夹 ID 的用户可以留空继续使用原目录；填写原目录路径并保存会替换旧设置，不会移动附件。

### 百度

- 使用自己的百度开放平台应用，填写 AppKey 和 SecretKey 后扫码授权。高级设置仍支持授权码或已有 Token。
- 填写已创建且在应用权限范围内的专用目录，例如 `/apps/你的应用名/Zotero`。插件会在其中创建 `zotero` 子目录。
- Token 刷新只调用 openapi.baidu.com，不使用第三方授权中转。

## 与 Zotero 原有功能的关系

- **保存设置并启用后，个人库附件由本插件入口负责。** 原生同步按钮及自动同步继续处理条目数据，并保留其他库原有处理行为；它们不会替你开启这个临时网盘服务。
- 插件按钮同步个人库。群组库不使用本插件的百度/夸克存储。
- 附件按“同步时下载”处理；缺失附件不能在空闲时自动连接网盘。打开缺失附件会提示先运行插件同步。
- 不会把原生 WebDAV URL、密码或存储协议改写为临时本机地址。通过运行期间的同步控制器适配接入，因此依赖 Zotero 内部接口，版本变化可能需要更新。
- 第一次使用某个网盘目录，或切换目标时，会调用 Zotero 自身的 resetAllSyncStates() 重新检查个人库附件。此操作修改本地附件同步状态，可能导致整库重新上传/下载检查；不会自动把旧网盘迁移到新网盘。
- 停用或卸载插件后，原有同步入口恢复原行为；原有附件存储设置可能重新生效。先确认原生设置，再继续同步。
- 不修改“全文文本同步”选项。条目、笔记以及用户已启用的全文文本同步仍按 Zotero 原有设置运行。

## 数据与凭据流向

附件数据路径：Zotero → 本机临时 WebDAV → 对应网盘 API、下载服务或网盘使用的对象存储/CDN。夸克上传可能使用阿里云 OSS 域名。这里的“直连”包括网盘使用的基础设施，并不等同于仅出现两个固定域名。

源码没有统计上报、远程执行或第三方文件中转功能。出站连接强制 HTTPS 并检查服务域名；API 不接受任意重定向，下载逐次检查重定向目标，并限制 Cookie/Authorization 转发。域名白名单不是恶意代码审计或端到端加密的替代品。

文件内容没有额外客户端加密，网盘运营方仍可能读取附件。Token/Cookie 在运行期间需要解密到 Zotero 进程内存；插件停用不会撤销它们。在已被控制的操作系统或恶意高权限插件环境中，不能承诺凭据保密。

网盘请求使用独立匿名 XHR，不进入 Zotero.HTTP 的请求日志，以减少 Token 被打印的风险；原生同步、系统网络诊断或第三方调试器仍可能记录其自身能够观察到的请求。不要公开未经检查的诊断日志。

## 当前限制

- 单个 Zotero 附件 ZIP 包默认上限 64 MiB，可调至 256 MiB；使用内存缓冲，同步期间内存会增加。
- 一次一个任务，网络请求有 120 秒超时。退出或取消会等待已开始的网盘请求结束；不承诺立即停止所有在途传输。
- 只验证受控测试覆盖的行为，不保证所有 PDF、快照附件、网络环境、网盘套餐或跨设备冲突场景都能成功。
- 夸克替换操作不是跨设备原子事务。异常时可能留下 cod-upload-*.tmp 或 cod-old-*.tmp；程序不会自动删除这些待检查文件。
- 当前没有双盘备份、后台计划任务、手机端本地桥接、网盘文件浏览器或自动更新。

## 开发与构建

需要 Node.js 18 或更高版本和 Python 3.8 或更高版本，无需安装 npm 或 Python 依赖。在项目根目录运行：

```sh
npm test
python scripts/build.py
```

构建脚本按自身位置解析路径，可从任意工作目录调用。打包后，安装包、SHA-256 校验文件和 `VALIDATION.json` 构建报告都位于 `outputs/`。插件没有远程更新服务，新版本通过本地 XPI 安装。

| 位置 | 内容 |
| --- | --- |
| 根目录 | 插件入口、同步实现、网盘适配器、设置页和清单 |
| `tests/` | 使用模拟网盘和模拟 Zotero 接口的自动化测试 |
| `scripts/` | 打包和隔离配置验证脚本 |
| `outputs/` | 安装包与构建输出，不提交到 Git |
| `work/` | 本地研究资料、临时配置及迁移快照，不提交到 Git |
