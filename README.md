# Zotero 网盘按需同步

把 Zotero **个人文献库的附件**同步到夸克网盘或百度网盘。同步由你手动发起，结束后插件关闭临时连接。文献条目、笔记和标签仍由 Zotero 官方同步。

**当前版本：0.2.2 · 仅支持 Zotero 10 · 实验版**

> [!WARNING]
> 真实网盘账号的端到端同步尚未验证。请先备份文献库，用测试库和专用网盘目录试用。网盘同步不能替代备份。

## 安装

仓库不跟踪 XPI 安装包。从源码打包需要 Python 3.8 或更高版本；无需安装第三方依赖。在项目根目录运行：

```sh
python scripts/build.py
```

打开 Zotero 的 **工具 → 插件**，点击齿轮菜单，选择 **从文件安装插件…**，选中生成的 `outputs/cloud-on-demand-0.2.2.xpi`。插件没有自动更新服务，升级时手动安装新版 XPI 即可。

## 配置网盘

打开 **工具 → 网盘按需同步 → 同步设置…**，选择一个网盘。请先在网盘里创建专用目录，再填写路径。

| 网盘 | 授权方式 | 专用目录示例 |
| --- | --- | --- |
| 夸克网盘 | 点击「夸克扫码登录」，用夸克 App 扫码确认。 | `/文献/Zotero` |
| 百度网盘 | 填写自己的百度开放平台应用 **AppKey** 和 **SecretKey**，点击「百度扫码登录」并确认授权。 | `/apps/你的应用名/Zotero`，目录须在应用授权范围内 |

路径以 `/` 开头，不能是根目录，末尾不加 `/`。夸克直接填完整路径，不用查文件夹 ID。插件会在专用目录下创建 `zotero` 子目录来存放附件，所以填写 `/文献/Zotero` 后，实际存储位置是 `/文献/Zotero/zotero/`。

如果扫码不可用，「高级」里保留了夸克的手动 Cookie 入口，以及百度的授权码和 Token 入口。已有凭据留空会保留；请勿在 Issue、聊天或日志里贴出 Cookie、SecretKey 和 Token。

## 开始同步

1. 先登录 Zotero 账号，并用 Zotero 自带的同步功能完成一次条目同步。
2. 回到插件设置页，确认已备份，勾选实验版确认并保存配置。保存配置不会连接网盘或传输附件。
3. 点击设置页底部的 **开始同步**，或使用 **工具 → 网盘按需同步 → 开始附件同步**。在设置页发起时，进度和错误会显示在底部。

保存并启用后，Zotero 自带的同步按钮仍同步条目，但不会为个人库启动网盘附件同步。缺失的附件需要先通过插件同步下载，不能在打开文件时自动连接网盘。停用插件后，Zotero 原来的附件同步设置会重新生效。

## 使用前须知

- **一次使用一个网盘。** 不支持双盘镜像或群组库附件同步。首次使用某个目录或更换目标时，Zotero 会重新检查个人库附件，可能重新传输文件；插件不会搬运旧网盘的数据。
- **旧配置可以继续用。** 如果旧版已经保存了夸克文件夹 ID，路径留空会沿用原目录。想换成路径配置时，填写同一个目录的完整路径并保存即可，不会移动附件。
- **大小限制按附件 ZIP 包计算。** 单个包默认上限 64 MiB，可调至 256 MiB；同步时实际内存占用可能高于包大小。
- **凭据加密，附件不额外加密。** 凭据通过 Zotero 的 OSKeyStore 加密后保存在本机，本地 WebDAV 只监听 `127.0.0.1`。附件经各自网盘服务及其存储端点传输，网盘服务方仍可能读取文件内容。

## 开发与验证

需要 Node.js 18 或更高版本和 Python 3.8 或更高版本。在项目根目录运行：

```sh
npm test
python scripts/build.py
```

插件源码位于根目录，测试位于 `tests/`，构建和隔离验证脚本位于 `scripts/`。XPI、SHA-256 校验文件和 `VALIDATION.json` 生成在 `outputs/`；本地测试配置放在 `work/`。这两个目录都不提交到 Git。

0.2.2 的 121 项自动化测试使用模拟后端，覆盖目录解析、配置迁移、协议读写和设置页交互。新版设置页也在隔离的 Zotero 10.0.8 中离线验证过加载、网盘切换和宽窄窗口布局。以上不代表已通过真实账号同步或跨设备冲突测试。

反馈问题时，请附上 Zotero 版本、插件版本、所选网盘和去除敏感信息后的错误提示。
